🌐 Nguyen Xuan Phuong's Portfolio

A **personal portfolio website** created by **Nguyen Xuan Phuong (XP)** to showcase skills, projects, and achievements in programming, design, and creative technology.

---

✨ Overview

This portfolio serves as an interactive résumé — a digital space to explore my:
- Technical and creative **skills** in coding, AI, and design  
- **Projects** ranging from AI-powered applications to interactive media  
- **Achievements** in academics and competitions  
- **Contact information** for collaboration or networking  
The website is designed to be cute, minimalistic, and responsive, with a smooth dark/light mode toggle and background audio for atmosphere.

🌙 Dynamic UI
- **Dark/Light Mode Toggle** – Seamlessly switch between modes using a floating button.  
- **Particle Background Animation** – Soft animated particles for an elegant aesthetic.  
- **Lofi Background Music** – Gentle looping audio for a relaxed viewing experience.
